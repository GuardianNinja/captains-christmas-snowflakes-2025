# Captain's Christmas Snowflakes 2025

Each person gets a **unique digital snowflake** based on their input  
(name, handle, phrase, anything).

This is inspired by a simple wish:

> "Can everyone be given a very unique snowflake for Christmas this year from the captain, a digital snowflake that’s very unique to each person so they can remember this Christmas, please."

## How it works

- Open `index.html` in your browser.
- Type your name or any personal key.
- Click **Generate Snowflake**.
- Click **Download Snowflake** to save it as a PNG.

The snowflake is generated deterministically from your input:
the same text will always produce the same snowflake,
and no two different inputs will look exactly the same.

## Tech

- Plain HTML, CSS, and JavaScript
- Canvas 2D drawing
- Simple string-based pseudo-random generator

No backend, no build step — just open and use.
